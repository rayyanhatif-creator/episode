# شفرة الكنز | Shifrat Alkanz

تطبيق عربي RTL لمسابقة البحث عن الكنز، مبني باستخدام React + Vite وSupabase.

## المتطلبات
- Node.js 20 أو أحدث
- مشروع Supabase

## التشغيل المحلي
1. نفّذ `npm install`.
2. انسخ `.env.example` إلى `.env.local` وأدخل عنوان Supabase ومفتاح anon/publishable.
3. لمشروع Supabase جديد: شغّل `supabase/schema.sql` في SQL Editor. إذا كانت قاعدة البيانات القديمة موجودة مسبقًا، شغّل `supabase/migrations/20261013_family_codes.sql` بدل إعادة تشغيل المخطط كاملًا.
4. شغّل `npm run dev`.
5. اختبر بناء الإنتاج باستخدام `npm run build` ثم `npm run preview`.

## إعداد المسابقة
1. من Supabase Authentication أنشئ مستخدمًا للمشرف باستخدام البريد الإلكتروني وكلمة المرور.
2. في SQL Editor، عيّن دور المشرف إلى `game_admin` باستبدال البريد في الاستعلام التالي ببريد المشرف:

```sql
update auth.users
set raw_app_meta_data = coalesce(raw_app_meta_data, '{}'::jsonb) || '{"role":"game_admin"}'::jsonb
where email = 'YOUR_ADMIN_EMAIL';
```

3. سجّل الدخول من زر «المشرف» في الموقع. من لوحة المشرف أنشئ رمزًا باسم كل أسرة، ثم انسخه وأرسله لها. الرمز مرتبط بفريق واحد، ويمكن للأسرة الدخول مجددًا باستخدام الرمز نفسه واسم الفريق نفسه.
4. أضف أول مرحلة من SQL، واستبدل نصوص المثال قبل الاستخدام:

```sql
insert into public.stages(title,sort_order,description,prompt,answer_hash,hint,status,points_reward)
values('البداية',1,'أول خيط في رحلة الكنز','اكتب نص اللغز هنا',
 encode(extensions.digest(lower(trim('الإجابة الصحيحة')),'sha256'),'hex'),
 'تلميح اختياري','current',100);
```

5. بعد تجهيز المرحلة والرموز، افتح المسابقة:

```sql
update public.game_settings set is_open=true, updated_at=now() where id=true;
```

لا تسمح للمتصفح بتعيين دور المشرف، ولا تضع مفتاح `service_role` في الواجهة.

## الأمن
- لا تضع مفتاح `service_role` في المتصفح أو في متغيرات `VITE_*`.
- لا تُعرض `answer_hash` أو `session_token_hash` ضمن البيانات العامة.
- سياسات RLS تحصر تعديل الجداول الحساسة بالمشرف.
- رمز جلسة الفريق عشوائي ويُخزّن كبصمة SHA-256، ويعاد نصه الخام مرة عند إنشاء الجلسة.
- دالة الإجابة الحالية تتحقق من تطابق SHA-256 بعد trim/lowercase فقط؛ إذا أردت إزالة التشكيل أو توحيد الحروف العربية، يجب تنفيذ التطبيع نفسه على الخادم عند إنشاء البصمة والتحقق منها.
- قبل المسابقة الحقيقية، أضف rate limiting وحماية تخمين الرموز، واختبر الصلاحيات وسلوك Realtime.

## الموجود في النسخة الحالية
- واجهة عربية RTL متجاوبة بتصميم أخضر داكن وذهبي.
- دخول فريق، صفحة لغز، تلميح، ترتيب فرق، ولوحة مشرف.
- إنشاء مرحلة من لوحة المشرف مع تخزين بصمة الإجابة.
- مخطط Supabase مع RLS وRPC وسجل تدقيق مبدئي.
- وضع معاينة يعمل دون Supabase، لكنه لا يحفظ بيانات حقيقية ولا يتحقق من الإجابات.

## حالة الاختبار
لم يتم تشغيل أو بناء المشروع داخل بيئة تنفيذ متاحة في هذه الجلسة، لذا لا تعتبره مختبرًا بعد. نفّذ أوامر البناء واختبارات الأمن قبل تشغيله مع مشاركين.

## النشر
يمكن نشر الواجهة على Vercel أو Netlify. أضف متغيري البيئة في إعدادات الاستضافة وشغّل `npm run build`. تعمل قاعدة البيانات والمصادقة عبر Supabase.
