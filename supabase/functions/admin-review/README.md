# مراجعة الإجابات

هذا المجلد مخصص لإضافة Edge Function لمراجعة الإجابات يدويًا إذا كان نظام المسابقة يتطلب اعتماد المشرف قبل منح النقاط.

لا تضع مفتاح service-role في الواجهة. يجب أن تتحقق أي وظيفة خادمية من JWT ومن الدور game_admin، وتسجل قرارات المراجعة في audit_logs. المخطط الحالي يقبل الإجابة الصحيحة تلقائيًا عند تطابق البصمة؛ عدّل RPC إلى pending وأضف إجراء مراجعة خادمي إذا كانت الموافقة اليدوية مطلوبة.
